# Poster Mo 🎨

A clean, Canva-like poster design tool in a single HTML file. No backend, no build step — everything runs in the browser.

Inspired by the concept of [doory](https://github.com/shaongitbd/doory) (open-source Canva alternative), rebuilt from scratch for the OpenX series: vanilla JS + Canvas 2D, original code.

## Features

- **Canvas** — 5 size presets (1:1, 4:5, 9:16, 16:9, A4), custom background color
- **Text** — headings & body, 5 fonts (Dela Gothic One, Noto Sans/Serif TC…), size, color, bold, alignment
- **Shapes** — rectangle, circle, line with fill color & thickness
- **Images** — upload from device, aspect-fit resize
- **Edit** — drag to move, corner handles to resize, top handle to rotate, center snapping
- **Layers** — reorder (forward/backward/front/back), duplicate, delete, layer list
- **History** — undo / redo (Ctrl+Z / Ctrl+Y), clear all
- **Export** — PNG & JPG download

## UI

Fullscreen canvas, everything lives inside the hamburger (☰) drawer — just like the rest of the OpenX series. EN/繁中 toggle, white / silver / black themes, Dela Gothic One display type.
